# DevSecOps Demo Application

## 1. Nama Aplikasi & Fungsi
**DevSecOps Demo API**: Aplikasi REST API sederhana berbasis Node.js yang menyediakan endpoint otentikasi serta health check sistem.

## 2. Bahasa & Framework
- **Language**: JavaScript (Node.js)
- **Framework**: Express.js

## 3. Cara Menjalankan Aplikasi

   ```bash
   git clone [https://github.com/syechabu10-tech/devsecops-p5-0110225104.git](https://github.com/syechabu10-tech/devsecops-p5-0110225104.git)

2. Install dependecies:
   ```bash
   npm install
   
3. Jalankan aplikasi:
   ```bash
   npm start
